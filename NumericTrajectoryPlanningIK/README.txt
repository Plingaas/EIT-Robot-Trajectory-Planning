1. To use the program in this folder, open "create-json"
2. Find "goalPose" and change it to the vector you want the UR5e to find
3. When it is finished running, run "main" one level up from this README
4. Watch the beautiful simulation :D
5. (It is possible to change more parameters than goalPose, quite a lot of them. However there has been little testing on them so bugs will happen!)
6. Have Fun!
